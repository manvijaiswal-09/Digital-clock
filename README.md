# Digital-clock

A simple and responsive **Digital Clock** built using **HTML, CSS, and JavaScript**. The clock updates every second and displays the current time in real time with a clean and modern interface.

## 🚀 Features

- Displays the current time in real time
- Updates automatically every second
- Clean and responsive design
- Beginner-friendly JavaScript project
- Lightweight and easy to customize

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

